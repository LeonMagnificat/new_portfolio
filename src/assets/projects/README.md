# Project Images

Place your project images in this directory with the following names:

## UI/UX Projects
- `UIUX-meritios.png` - Meritios project image
- `UIUX-consultified.png` - Consultfied project image
- `UIUXmobila.png` - MobilaDoktor Admin project image

## Development Projects
- `solid.png` - Solid Apps project image
- `Morphorosic.png` - Morphorosic Calculator project image
- `ino.png` - Ino SaaS project image

## Branding Projects
- `branding-Ndiho.png` - Ndiho Branding project image
- `consultified-logo.png` - Consultified Branding project image

The application will automatically use these images when they are available. If any image is missing, a placeholder will be shown instead.
